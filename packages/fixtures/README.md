# @bioforge/fixtures

The fixture corpus for deterministic, reproducible testing (PRD §11, Step 0).

**Everything here is illustrative** until real scientific tools and scientific-owner
sign-off land (ADR-D10). Fixtures are labeled so nothing is mistaken for real evidence.

As each PRD §11 scenario's step is implemented, its fixture is added here with a known
expected outcome, so the Phase 6 fixture test matrix (Step 6.1) can assert the PRD's
"Expected result" for every row.
